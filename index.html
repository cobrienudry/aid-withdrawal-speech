Aid Withdrawal Speech: RA coding

How do African governments, donors and publics talk about foreign aid, and about its withdrawal? Research assistants read news articles from African media (October 2024 – October 2025), identify every speech act, and code the theme of each one.

What you will do

  1. Read the codebook in full before your first batch. Keep it open in another tab while you code.
  2. Get your batch file (e.g. EN-B03.json or FR-B07.json) from the project lead. Each batch has about 25 articles. Do not share batch files: they contain full article text.
  3. Open the coding tool, type your initials, and drag the batch file in. Your work saves automatically in this browser.
  4. For each article, find every speech act (a statement attributed to an identifiable speaker). Select the quote in the text and click + Speech act from selection, then fill in the speaker and the theme.
  5. Mark the article done and move to the next one. If there are no speech acts, tick No speech acts; if the text is broken, flag it.
  6. Export when you finish a session: Export CSV for submission and Backup to keep a copy. Upload both to the shared project folder.

What counts as a speech act

One statement, direct or reported, attributed to an identifiable speaker: a named person (“Minister Pate said…”) or a named organisation (“UNICEF warned that…”). The journalist's own narration is not a speech act. If one speaker makes several distinct points, record each as a separate act when they would get different themes.

Important

  • Work is stored only in your browser on this computer. Clearing browser data deletes it, so export a backup at the end of every session. To continue on another computer, load the backup file instead of the batch file.
  • Use the same browser and the same initials every time.
  • Nothing you code is sent anywhere until you upload the exported files yourself.
  • Questions or unclear cases: write them in the notes field and set confidence to 1 – hard call; raise recurring problems at the weekly meeting.
